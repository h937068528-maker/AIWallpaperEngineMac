AIWallpaperEngineMac 2.7
安装与功能介绍

一、产品介绍

AIWallpaperEngineMac 是面向 macOS 的原生动态壁纸引擎。
本版本针对 Apple Silicon Mac 构建，支持视频、GIF、Live Photo 和 Metal GPU 粒子互动壁纸。

二、主要功能

• MP4 动态壁纸
• GIF 动态壁纸
• Live Photo 动态壁纸
• 原生在线壁纸库：支持搜索、分类、预览、下载和一键应用
• 在线壁纸下载完成后自动加入本地壁纸库
• JPG、JPEG、PNG 原生静态壁纸与多显示器应用
• 多来源壁纸目录：动态壁纸、Bing 每日壁纸、本地文件夹
• 支持添加用户自己的 GitHub 壁纸仓库和 HTTPS 静态图片目录
• Metal 实时粒子、波纹和鼠标互动效果
• 多显示器壁纸选择
• 粒子数量、尺寸、互动范围、作用力、回归速度和目标帧率调节
• 省电、平衡和高质量粒子档位
• 电池模式：使用电池时限制实时渲染帧数并降低视频资源占用
• 电量低于 20% 或系统开启低电量模式时自动暂停
• 全屏应用覆盖显示器时按屏幕独立暂停
• 24、30、60、120 FPS 实时渲染帧数控制
• 登录时自动启动
• 简体中文、English 和跟随系统语言
• 全屏应用、低电量及屏幕不可见状态下自动暂停或降低负载

三、安装方法

1. 打开 AIWallpaperEngineMac-2.7-Full-GPU-Particles-arm64.dmg。
2. 将 AIWallpaperEngineMac 拖入 Applications（应用程序）文件夹。
3. 在“应用程序”中打开 AIWallpaperEngineMac。
4. 如果 macOS 首次运行时显示安全提示，请在 Finder 中右键应用并选择“打开”，然后确认。

四、基本使用

1. 在“在线壁纸”页面选择动态壁纸、Bing、本地文件夹或自定义来源。
2. 点击“添加来源”可以连接用户自己的 GitHub 仓库或 HTTPS 图片目录。
3. 搜索、预览并下载壁纸，下载后可直接应用。
4. 打开本地壁纸库并选择包含图片、MP4、GIF 或 Live Photo 的文件夹。
5. 选择目标显示器，点击壁纸卡片即可应用。
6. 在“特效”页面可以选择 Metal 或粒子互动壁纸。
7. 在“设置 → 性能与电池”中调整电池模式、低电量暂停、全屏暂停和帧数。
8. 普通桌面模式不会拦截桌面图标操作。
9. 按住 Option 键可临时开启完整鼠标互动，松开后自动恢复桌面穿透。

五、系统要求

• macOS 14.6 或更高版本
• Apple Silicon：M1、M2、M3、M4 或更新芯片
• 高质量粒子模式建议在接通电源时使用
